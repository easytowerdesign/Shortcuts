Bluebeam Revu Quick Reference

Keyboard Shortcuts

  • L - Line
  • R - Rectangle
  • C - Cloud
  • E - Ellipse
  • P - Sketch Free Hand
  • T - Text Box
  • M - Measure
  • Alt + 0176 - Degree Symbol (°)
  • Alt + 0216 - Diameter Symbol (Ø)

Pinning a Document

  1. Open the File Access panel.
  2. Locate the desired PDF under Recents.
  3. Right-click the file.
  4. Select Pin → Pin File.
  5. The document will appear in the Pinned section for quick access.

Example:

Convert Rectangle to Highlight

  1. Draw a rectangle around the text you want to highlight.
  2. Select the rectangle.
  3. Open the Properties panel.
  4. Set the Fill Color to yellow (or another highlight color).
  5. Reduce the Opacity to approximately 20% to 40%.
  6. Set the border color to match the fill color or make it transparent.
  7. The rectangle will now function as a text highlight while remaining editable.

Compare Documents

  1. Select Document → Compare Documents.
  2. Choose the original PDF.
  3. Choose the revised PDF.
  4. Review page alignment settings if prompted.
  5. Click OK.
  6. Bluebeam creates a new PDF highlighting all detected differences.
  7. Review the generated markups to quickly identify changes between document revisions.
