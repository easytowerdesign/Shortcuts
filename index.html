Keyboard Shortcuts

  • L - Line
  • R - Rectangle
  • C - Cloud
  • E - Ellipse
  • P - Sketch Free Hand
  • T - Text Box
  • M - Measure
  • Alt + 0176 - Degree Symbol (°)
  • Alt + 0216 - Diameter Symbol (Ø)

Pinning a Document

  1. Open the File Access panel.
  2. Locate the document under Recents.
  3. Right-click the file.
  4. Select Pin → Pin File.
  5. The document will appear in the Pinned section for quick access.
Tip: Pinned files remain readily accessible from the File Access panel.

Convert Rectangle to Highlight

  1. Select the rectangle markup.
  2. Right-click the rectangle.
  3. Select Change Markup Type → Highlight.
  4. The rectangle will be converted into a highlight markup.
  5. Adjust color and appearance as required.

Compare Documents

  1. Select Document → Compare Documents.
  2. Choose the original PDF.
  3. Choose the revised PDF.
  4. Confirm page alignment settings if prompted.
  5. Click OK.
  6. Bluebeam generates a new PDF
