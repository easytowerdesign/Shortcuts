Bluebeam Revu Quick Reference

Keyboard Shortcuts

  • L - Line
  • R - Rectangle
  • C - Cloud
  • E - Ellipse
  • P - Polyline
  • T - Text Box
  • M - Measure
  • Alt + 0176 - Degree Symbol (°)
  • Alt + 0216 - Diameter Symbol (Ø)
  • Θ - Theta Symbol

Pinning a Document

  1. Open the PDF in Bluebeam Revu.
  2. Right-click the document tab.
  3. Select Pin Tab.
  4. The tab remains fixed at the beginning of the tab list.

Convert Rectangle to Highlight

  1. Draw a rectangle around the desired text.
  2. Select the rectangle.
  3. Open the Properties panel (Alt+P).
  4. Set the Fill Color to yellow or another highlight color.
  5. Reduce Opacity to approximately 20% to 40%.
  6. Set the border color to match the fill color or make it transparent.
  7. The rectangle now functions as a highlight while remaining editable.

Compare Documents

  1. Select Document → Compare Documents.
  2. Choose the original PDF.
  3. Choose the revised PDF.
  4. Verify page alignment settings if prompted.
  5. Click OK.
  6. Bluebeam creates a new PDF showing all detected changes.
  7. Review the generated markups to quickly identify differences.
